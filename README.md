# SQL Fundamentals: Interactive Documentation

**[View Live Demo](https://tubolyroli.github.io/sql-fundamentals/)**

Designed for students and data professionals.

## 🚀 Features

- 🔍 Searchable
- 📑 Interactive TOC
- 🌓 Dark Mode Support
- 📋 Copy-to-Clipboard
- ✅ Checklist Integration
- 📱 Responsive Design

## 📖 How to Use

1. Clone the repository: `git clone https://github.com/tubolyroli/sql-fundamentals.git`
2. Open `index.html` in any modern web browser.
3. Use the sidebar to navigate or the search bar at the top to find stuff you are looking for.

## 🛠️ Built With

- 🌐 HTML5/CSS3
- ⚡ Vanilla JavaScript
- ✨ Highlight.js
